Python Introduction

Python is a high-level interpreted programming language with many applications, such as machine learning, web development, software development and mathematics. This tutorial is tailored for beginners who want to understand the basics of python by giving them basic commands, starting off with learning the python syntax which is like the "grammar" of the programming language. Beginners will understand how to print output onto a screen, how to interpret and write conditional statements such as if and else, how to declare and alter variables and learn about the different data types present, how different loops work such as the for and the while loops, and so on. By the end of this tutorial, beginners should be capable of creating code in python, be comfortable analyzing their own and others' code, and act as a solid foundation for further learning.
